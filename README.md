# perfume-prise-monitor
# Мониторинг цен на парфюмерию — три агента

Для магазина парфюмерии: цены четырёх розничных конкурентов, закупка Delice Opt и предварительная рекомендация цены продажи.

**Начните с [THREE_AGENTS_GUIDE.md](THREE_AGENTS_GUIDE.md)** — там восстановление проекта с нуля на Windows, вход к поставщику и запуск через интерфейс.

Три независимых процесса:

1. `agent_competitors.py` — Золотое Яблоко, Randewoo, Л’Этуаль, Рив Гош; строгие карточки, ограничение 24 часа, ручное подтверждение при блокировке.
2. `agent_supplier.py` — только текущая карточка Delice Opt через отдельную локальную авторизацию и реестр прямых ссылок.
3. `agent_pricing.py` — офлайн-сопоставление двух JSON-отчётов, минимальная наценка после введённых расходов, предварительный рыночный ориентир только по пригодным ценам.

Общий запуск:

```powershell
python create_test_input.py
python run_three_agents.py --input test_products.xlsx --output recommendations.xlsx --offline --supplier-disabled
```

Без подтверждённых источников результаты остаются пустыми, а не заполняются примерными ценами. Подключение к реальным сайтам на Windows и новая авторизация поставщика требуют локальной проверки.

Предыдущий интерфейс `perfume_monitor.py`, гибридная SQLite-база и остальные команды сохранены для совместимости. Старые инструкции: [HYBRID_GUIDE.md](HYBRID_GUIDE.md).
