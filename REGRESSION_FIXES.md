# Исправления после Windows-запуска, 16 ноября 2026

## Подтверждение и границы проверки

Пользователь сообщил: 5 ароматов, 3 закупки, 0 из 20 розничных цен. В текущем сообщении файл monitoring.xlsx не поступил: доступны только исходники из предыдущего ZIP. Поэтому конкретная причина отказа Creed Aventus EDP 100 мл и Creed Green Irish Tweed EDP 100 мл на Windows не установлена. Доступа к пользовательской авторизованной сессии Delice Opt нет.

99 автоматических тестов прошли, включая настоящий Chromium с локальными HTML-фикстурами. Живые розничные цены этим обновлением не подтверждены, исправления не объявляются полностью проверенной интеграцией с текущими сайтами.

## Изменения

- Randewoo / Playwright: решение по маршруту готовится отдельно от fulfill/abort. После попытки терминального действия второе действие не выполняется даже при исключении. Гонка с закрытием контекста фиксируется без повторного завершения. Тесты воспроизводят Route is already handled! в fetch, fulfill и abort.
- Ошибки необязательного ресурса, например запрет картинки robots.txt, больше не становятся автоматически отказом основной карточки. Запреты ресурсов соблюдаются; ошибки документа остаются фатальными для текущего магазина.
- Лэтуаль / robots.txt: обычные 404/410 означают отсутствие опубликованного файла правил, а не Disallow. Это соответствует RFC 9309 §2.3.1.3. Защитная HTML-страница даже с кодом 404 не даёт разрешения; 401/403/429, 503 и реальные Disallow останавливают соответствующий запрос. Условия использования магазина продолжают учитываться через store_policies.json.
- Золотое Яблоко: ожидание видимого поля после гидратации, выбор видимого вместо скрытого input, открытие панели по доступному имени кнопки/семантическим атрибутам. Резерв — только поисковая ссылка, реально обнаруженная в текущем header. Подсказки собираются до Enter и сохраняются после навигации. Endpoint не угадывается. Удалено запоминание единичного сбоя UI как основания пропускать другие товары и сохранённые карточки этого магазина.
- Рив Гош: HTTP 503 записывается в сетевую диагностику и причину отказа, цена остаётся пустой. Защитная страница даёт blocked; обычный 503 — unavailable. Другие магазины обрабатываются; тест проверяет выполнение магазина после ошибки Рив Гош.
- Delice Opt: эквивалентные написания концентрации п.в./п/в/парф. вода обрабатываются как EDP, т.в./т/в/туал. вода — как EDT. Это точная нормализация, не нечёткое сопоставление. Отдельный бренд учитывается только из поля той же строки предложения. Числовой объём без единицы принимается только с явным data-unit или заголовком соответствующей колонки «Объём, мл». Цена без валюты требует доказательства RUB в своём поле/колонке. Колонки других валют не используются.
- Delice Opt: добавлен лист «Проверка закупки» в *_supplier.xlsx. Для каждой строки показаны фактическое название/бренд, объём, концентрация, отдельные флаги совпадения и конкретные причины отказа. Сводная диагностика наследует эти причины. Отсутствие единицы/концентрации не заменяется значением из запроса. Aventus Cologne, EDT вместо EDP, другие объёмы, тестеры и наборы по-прежнему отклоняются.

## Неизменные данные

Вызов launch_persistent_context, путь supplier_browser_profile, headless=False, locale ru-RU и способ авторизации не изменены. Локальный supplier_links.json побайтово совпадает с исходным. Он, products.csv, cookies, токены и профиль не входят в публичный ZIP. Отчёты и журналы пользовательского сеанса не публикуются.

## Установка

Распакуйте новый ZIP в существующую папку с заменой исходников. Сохраняйте свой профиль, supplier_links.json и products.csv. Если test_products.xlsx уже существует, генератор повторно запускать не требуется.

Команда мониторинга: `python batch_monitor.py --input test_products.xlsx --output monitoring.xlsx`.
Тесты: `python -m pytest tests -q`.

Для точного расследования двух закупок результат следующего локального запуска содержит отдельный лист «Проверка закупки» в файлах batch_details/*_supplier.xlsx. Запрашиваемый вариант не подменяется похожим товаром.
