# Гибридный мониторинг — Windows

## Установка обновления

Закройте агент, сохраните копию исходников и распакуйте ZIP в существующую папку `C:\Users\User\perfume-browser-agent` с заменой Python-файлов. Не удаляйте проект целиком. Ваши `supplier_links.json`, `products.csv`, `supplier_browser_profile` и, после первого запуска гибридного режима, папка `local_data` должны остаться на месте.

Установите зависимости в используемом окружении: `python -m pip install -r requirements.txt`. При необходимости: `python -m playwright install chromium`. Добавлена tzdata для поддержки часового пояса на Windows.

Одна команда запуска интерфейса:

```powershell
python perfume_monitor.py
```

## Подтвердить цены без редактирования кода

1. Нажмите «Подтвердить цены». Выберите строку реестра или заполните бренд, название без бренда, концентрацию, объём, магазин и прямой URL.
2. Нажмите «Сохранить ссылку». Ссылка проверяется по HTTPS и домену магазина, но сама по себе не подтверждает цену или вариант товара.
3. Нажмите «Открыть карточку»: откроется ваш обычный браузер. Если автоматизация заблокирована, проверяйте вручную в допустимом для магазина режиме. Профиль/пароль в агент не передаются.
4. Убедитесь, что это точный бренд/аромат/концентрация/объём и не тестер/набор. Введите увиденную цену в RUB и фактическую дату проверки ISO 8601 с часовым поясом. Текущее время уже подставлено, его можно изменить.
5. Отдельно поставьте три флажка подтверждения названия, концентрации и объёма. Укажите наличие, продавца и тип цены. `store` означает продавца самого магазина, `third_party` — стороннего продавца. Неизвестный продавец отмечается `unknown`.
6. Нажмите «Сохранить подтверждение цены». После этого повторите мониторинг для обновления Excel. Сохранение ссылки и подтверждение цены — разные операции.

`regular` — обычная цена; `loyalty` — по карте; `coupon` — по промокоду. Для условных цен требуется описание условий; они сохраняются в истории, но не подменяют обычную цену в сравнении.

## Срок актуальности

По умолчанию 24 часа с указанного пользователем времени проверки. Ровно на границе срока цена уже просрочена. Время не обновляется при повторном мониторинге. Дата в будущем, отсутствие часового пояса, несовпадение идентичности и неподтверждённые флажки отклоняются.

Срок в форме можно задать для конкретного подтверждения; кнопка «Срок по умолчанию» сохраняет настройку для новых подтверждений. Существующие записи не получают новую дату или продление автоматически. В CLI параметр `--manual-ttl-hours 12` явно переопределяет срок чтения для данного отчёта.

Изменение URL карточки не переносит на неё цену от предыдущего URL. При другой концентрации или объёме используется отдельная запись.

## Автоматический и ручной режим

Playwright сначала проверяет сохранённую карточку, затем пробует поиск при разрешённом доступе. Обычная пропавшая карточка 404/410 может привести к поиску; запрет robots.txt, CAPTCHA и защитная страница не обходятся ради поиска.

Актуальная автоматическая цена имеет приоритет. Если автоматическое чтение не подтверждено, используется только актуальное ручное подтверждение точного товара и того же URL. В диагностике остаются исходный статус/причина автоматического отказа и настоящий канал цены. При просрочке цена остаётся только в истории и не участвует в сравнении.

Для работы без автоматических запросов к конкурентам поставьте флажок «Без автосбора конкурентов (для массового запуска)» и запустите массовый мониторинг. Закупка при этом по-прежнему проверяется через существующую авторизованную сессию поставщика.

CLI: `python batch_monitor.py --input test_products.xlsx --output monitoring.xlsx --offline`.

Для технического запуска вообще без запросов поставщику добавьте `--supplier-disabled`. Без подтверждённой закупки расчёт минимальной цены и прибыли не производится; ручные конкурентные цены при этом сохраняются в отчёте.

## Постоянные данные

`local_data/competitors.sqlite3` — реестр и история ручных цен. В нём нет cookies, паролей или токенов; сами введённые цены могут быть конфиденциальными. Храните резервную копию локально. Эта база никогда не включается в GitHub или ZIP.

При первом запуске импортируются две публичные ссылки Creed Green Irish Tweed EDP 100 мл, ранее проверенные по веб-представлениям Лэтуаль и Золотого Яблока. Статус явно указывает на прошлую проверку идентичности; цена не импортируется. Существующий products.csv также импортируется как набор непроверенных ссылок, без изменения исходного файла. Повторный импорт не заменяет внесённые пользователем ссылки.

## Закупка и Excel

Авторизация Delice Opt, путь и параметры запуска профиля не менялись. Все обнаруженные варианты закупки отображаются на листе «Проверка закупки»: название, бренд, объём, концентрация, комплектация, цена строки, продавец, URL и причины отказа. Цена неподходящей строки видна только как диагностическая цена и не участвует в расчёте. Закупка выбирается только из строго совпадающих предложений. Для двух Creed при отсутствии совпадения остаются отдельные причины отказа; реальная цена не выдумывается.

Итоговые листы:
- «Сводный отчёт»: закупка, четыре конкурента, канал/время/актуальность, минимальная/рекомендованная цена, прибыль, основание рекомендации.
- «Диагностика»: точность товара, цена, источник, причины автоматического отказа и актуальность.
- «Проверка закупки»: все варианты поставщика и их проверка.
- «Ручное подтверждение»: ссылки, история ручных цен, дата и срок действия, условия и действие для пользователя.

При наличии подтверждённой закупки и отсутствии пригодных рыночных данных рассчитывается только порог затрат с наценкой не менее 15%. Он явно подписан как минимальная цена, а не оптимальная рыночная. Если и закупка отсутствует, расчётные цены пусты. Рыночный ориентир использует только подтверждённые обычные предложения InStock с явно указанным продавцом самого магазина.

Excel атомарно сохраняется после каждого аромата. Не держите целевой файл открытым в Excel во время перезаписи на Windows.

## Проверено и что остаётся проверить

143 автоматических теста прошли, все прежние тесты сохранены. Проверены сохранение/повторное открытие SQLite, ручные подтверждения, граница 24 часов, изменение TTL, неправильные объёмы/концентрации/комплектация, приоритет источников, прямые ссылки до поиска, отказ от обхода защиты, расчёт наценки и промежуточное сохранение.

Все пять тестовых ароматов прошли локальный интеграционный сценарий с синтетическими ручными ценами и недоступной сетью. Отдельный настоящий CLI-запуск без сетевых запросов обработал пять строк и создал четыре листа: 25 диагностик и 20 предложений ручного подтверждения. Синтетические цены существуют только в тестовых временных файлах. Актуальные реальные розничные цены этой проверкой не подтверждены.

На Windows требуется проверить визуальное отображение Tkinter, открытие карточек системным браузером, сохранение/повторное открытие ручных данных, доступ вашей сессии Delice Opt и настоящий ответ каждого магазина. Графическую сессию Windows и ваш профиль из облака проверить нельзя. Google Drive и расписание не подключены.
