# Три независимых агента — полное восстановление на Windows

Эта сборка восстанавливается **в новую пустую папку**. Старые исходники или архивы не нужны.

## 1. Установка с нуля

1. Распакуйте архив в `C:\Users\User\` (или в домашнюю папку вашей учётной записи). Внутри архива уже есть папка **`perfume-browser-agent`**. В ней должны находиться `perfume_monitor.py`, `agent_competitors.py`, `agent_supplier.py`, `agent_pricing.py` и `requirements.txt`. Не создавайте вторую вложенную папку с тем же именем.
2. Откройте PowerShell в этой папке. Проверьте: `python --version` (поддерживается современный Python 3.11+).
3. Выполните:

   ```powershell
   python -m pip install -r requirements.txt
   python -m playwright install chromium
   python create_test_input.py
   ```

   Последняя команда создаёт `test_products.xlsx` с пятью названиями **без цен**. Если файл уже существует, команда не перезапишет его.

4. Запустите графический интерфейс: `python perfume_monitor.py`.
5. Выберите **«ЗАПУСТИТЬ 3 АГЕНТА»** и Excel со списком ароматов. Для запуска каждого агента отдельно используйте команды ниже.

Excel должен содержать столбцы `Аромат` и `Объём, мл`, например `Creed Green Irish Tweed EDP` и `100`. **Концентрация обязательна**: без неё система не смешивает похожие версии и останавливается с пояснением. Тестер, набор и отливант не сопоставляются с обычным флаконом.

## 2. После удаления папок: повторный вход к поставщику

Логин, cookies и сессия Delice Opt **не были опубликованы** в GitHub или ZIP. Если вы удалили локальный профиль, сначала выполните:

```powershell
python supplier_login.py
```

Откроется Chromium на `https://application.delice-opt.ru/`. Войдите **вручную** в свой аккаунт. Вернитесь в PowerShell и нажмите Enter. Новый `supplier_browser_profile` останется только на вашем компьютере.

Для каждого аромата добавьте действительную прямую ссылку на карточку в локальный файл `supplier_links.json` (скопируйте `supplier_links.example.json`, переименуйте копию и заполните). Пример структуры, где число `12345` — **только образец, замените на настоящий ID карточки**:

```json
{
  "creed green irish tweed edp|100": "https://application.delice-opt.ru/catalog/12345"
}
```

В имени ключа используйте название аромата в нижнем регистре, пробелы между словами, затем `|` и объём в мл. Например, `ex nihilo fleur narcotique extrait|100` — **другой** продукт, чем `ex nihilo fleur narcotique edp|100`.

Агент поставщика использует **только текущие предложения внутри точной карточки**, не берёт старые цифры из Excel или сохранённого URL. Без профиля и точной ссылки он помечает закупку как недоступную; цена продажи не рассчитывается. Наличие и окончательную стоимость заказа всё равно нужно перепроверить вручную.

## 3. Как работают агенты

| Агент | Скрипт | Выход | Доступ |
| --- | --- | --- | --- |
| 1. Конкуренты | `agent_competitors.py` | `work/competitors.json` | goldapple.ru, randewoo.ru, letu.ru, rivegauche.ru |
| 2. Поставщик | `agent_supplier.py` | `work/supplier.json` | application.delice-opt.ru, ваш локальный профиль |
| 3. Ценообразование | `agent_pricing.py` | `recommendations.xlsx` | **без интернета и браузера**, читает два JSON |

Вместе, одной командой:

```powershell
python run_three_agents.py --input test_products.xlsx --output recommendations.xlsx
```

Для проверки без обращения к сайтам:

```powershell
python run_three_agents.py --input test_products.xlsx --output recommendations.xlsx --offline --supplier-disabled
```

**В офлайн-проверке без данных не появятся придуманные цены.** В конечном Excel будут указаны причины отсутствия закупки и рыночных цен. Если ранее вручную проверенные цены сохранены в `local_data/competitors.sqlite3`, первый агент возьмёт только действующие подтверждения, сроком до 24 часов.

Отдельные команды:

```powershell
python agent_competitors.py --input test_products.xlsx --output work/competitors.json
python agent_supplier.py --input test_products.xlsx --output work/supplier.json
python agent_pricing.py --competitors work/competitors.json --supplier work/supplier.json --output recommendations.xlsx
```

После каждого товара агент атомарно сохраняет свой JSON; третий агент сверяет одинаковые точные названия/концентрации/объёмы, структуру и наличие **всех четырёх** магазинов. Если первый или второй агент завершился ошибкой, общий запуск не запускает третий на старых данных.

## 4. Рекомендация и расходы

Третий агент берёт только цены, подтверждённые менее 24 часов назад (с часовым поясом). У конкурентов допустимы только обычные цены **InStock** от самого магазина, не от сторонних продавцов, не по карте и не по промокоду. Ранее вручную проверенные цены не продлеваются при новом запуске.

Предыдущий осторожный порог сохраняется:

`Минимум = округление вверх ((закупка × 1,15 + доставка/упаковка + прочие расходы) / (1 − доля комиссии − доля налога))`

При наличии подходящей цены конкурента итог не ниже минимального порога; по умолчанию ориентир — на 100 ₽ ниже самого дешёвого допустимого конкурента. **Это наценка 15% к закупке после указанных расходов, а не маржа 15% от выручки.** Расходы в новом интерфейсе первоначально равны нулю: заполните **свои реальные** значения до продаж. Например, через CLI можно передать `--shipping`, `--other`, `--commission-pct`, `--tax-pct`, `--undercut`, `--markup-pct` (не менее 15).

Если нет текущей закупки — нет рекомендации. Если есть закупка, но нет подходящей цены ни одного конкурента — отображается **только минимальная допустимая цена**, не «рыночный оптимум». Все исключения видны на вкладке «Проверка источников»; все предложения Delice Opt, включая неподходящие, — на вкладке «Проверка закупки».

## 5. Ограничения и восстановление личных данных

- Ограничения магазинов, CAPTCHA и robots.txt не обходятся. При отказе автоматического чтения первый агент предлагает проверить цену вручную в окне **«Подтвердить цены»**.
- Предыдущие данные `local_data/competitors.sqlite3`, `supplier_links.json`, `supplier_browser_profile`, `products.csv` и ранее созданные Excel **не входят** в архив. Если удалены без отдельной резервной копии, их придётся создать повторно. Старые цены не объявляются свежими.
- Если аккаунт Delice Opt требует входа на новой машине, действующую сессию нужно создать заново. Никакие пароли в GitHub не загружаются.
- Автоматическая проверка реальных сайтов и графического интерфейса зависит от локального Windows и аккаунта; наличие рабочих модулей и тестов не доказывает наличие актуальных живых цен.
- Google Drive и расписание в этой сборке не подключены.

Для технической самопроверки: `python -m pytest tests -q`.
